## R3 — Stable bar  [x]

- [x] `dot` and `doh` are Stable. Condition 1 had been false for both (the second "client" used
  the server's own codec); BIND `dig` is now the second client, both reading six record kinds.
- [x] DoT and DoH had their own answer loops (empty answers left the resolver waiting or gave

- [x] The DNS server's TCP path sent an over-64 KiB answer as a truncated NOERROR; it is SERVFAIL.
