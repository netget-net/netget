# OCI Registry client

Selected Distribution v2 reads: probe, catalog, tags, manifest and blob GET/HEAD. No registry content database, credentials file/helper, upload/delete, recursive image pulling, platform selection, referrers/fallback, foreign URL following, Range/resume or redirect following. Native HTTP and certificate-verified HTTPS; browser HTTP implementation only, with no browser runtime evidence or positive TLS interoperability claim.

`oci_request` accepts one selected operation, a strict lowercase repository (255 bytes) except probe/catalog, and a manifest tag (128 bytes) or lowercase sha256 digest. Blob requires a digest. Tags/catalog use explicit n1..1000 (default100) and optional last cursor. Blob optional expected_size verifies a supplied descriptor size up to4MiB. Unknown fields and raw method/URL/query/body passthrough are refused before I/O. `disconnect` cancels owned pending I/O.

Manifest GET accepts OCI image manifests/indexes and Docker v2 schema2 manifests/lists, schemaVersion2, typed config/layer/child descriptors, optional subject/artifactType and string annotations. Descriptor size is unsigned, mediaType is bounded, digest is sha256, optional platform needs architecture/os. Embedded descriptor data is outside this selected scope. Unknown bounded extension fields remain native metadata. Hash exact raw response bytes before exposing the manifest; requested digest and any optional Docker-Content-Digest must match. Legacy Docker headers are optional. HEAD reports native existence, digest and size with digest_verified=false; no content hash is inferred.

Blob GET hashes the complete response against its requested digest and optional native digest/expected_size. Only valid UTF8 up to64KiB appears as text. Binary or larger text has text=null and content_omitted=true with verified digest and byte size. No files are written. Descriptors/URLs do not trigger implicit downloads.

Tags/catalog validate repository echo, list entries/order/duplicates and page count. Native relative same-route Link rel=next is reduced to a validated last cursor; optional n must match the selected count. No Link with a full n-page yields next_last plus continuation_source=count_fallback and pagination_complete=false. A shorter page without Link establishes completion. This avoids treating optional Link absence as proof that a full page is final. Paging is always a separate explicit action. Registry list/error bodies accept absent, application/json or text/plain media types, but always require bounded typed JSON; crane0.22.1 independently uses text/plain for tag JSON. Token-service JSON remains application/json, and manifest media validation is separate.

Startup request_timeout_secs defaults15, range1..30, covering DNS/connect/headers/body. The public unauthenticated `/v2/` probe must produce200 or a selected401 Bearer challenge. Startup token presence never means authentication was verified. Startup token is bounded16KiB and only sent on subsequent explicit requests. Proxy selection, cookies, redirects, decompression and idle connection reuse are disabled.

`oci_authenticate` uses the last native401 challenge and GETs its realm with optional username (256 bytes)/password (16KiB) supplied together, or anonymously. The token origin must equal the registry or explicit startup trusted_token_origin. Credentials require verified HTTPS or numeric loopback HTTP; a hostname merely named localhost is not trusted for plaintext credentials. Realm userinfo/fragments/reserved auth query parameters are refused. Challenge attributes are quoted, duplicates refused, header4096 bytes/16 attributes/16 scopes, scopes restricted to the selected repository pull or catalog scope. Basic is only used for the token-service request. Authorization headers are sensitive. No registry Basic challenge, auth replay/retry, OAuth POST, refresh/offline token, JWT verification or bearer audience claim.

Token/access_token aliases must agree. Optional expires_in defaults60 seconds and is1..86400; optional issued_at is RFC3339, cannot be over30 seconds in the future or already expired. Honor the remaining transient lifetime. The authentication event says token_received=true and registry_authorization_verified=false; a later native registry response supplies separate authorization evidence. `oci_set_token` sets a bounded opaque transient bearer with authentication_verified=false. `oci_clear_token` stops sending it locally, without claiming server revocation. Keep only the latest bounded token/password/encoded Basic secret for reflection redaction until session drop, including after clear/expiry. Never expose them in events/status/incidental diagnostics. All event action definitions retain credential declarations so shared logging privacy remains active on every followup. Native fixed schema field names are preserved; reflected secrets in values and dynamic keys are redacted.

Bounds: response4MiB, manifest1MiB, JSONdepth32/nodes65536, strings64KiB, arrays1000, object fields256/keys256 bytes; duplicate keys/trailing JSON refused. Headers64/total32768 bytes/value8192 bytes. In-memory actions preflight depth32/nodes65536/retained-content8MiB before copying, and owned refusals are disposed iteratively. Converted event wrapper depth40 and retained8MiB/node65536; redaction has its own guarded walker and iterative disposal.

Two registered tasks own session/request state and common event dispatch. Command channel precedes the connected event, so manual handling cannot block injection. One pending operation, action/event queues8, shared injection16, four handler followups; fresh external actions reset the followup depth. Pending overlap is refused; disconnect/removal drops the request future and aborts owned handler/session. Parked event overflow ends the session explicitly. HTTP/schema/transport failures emit fixed bounded refusals and allow a fresh request without automatic retries or invented success. Injected Sent is returned only after a complete validated native response/local operation; it is not a claim of successful backend authorization and bytes_sent=0 is logical API acknowledgement, not a wire byte count.

Continuously queued overlap refusals cannot extend the whole request deadline or close the logical session: expiration cancels that request, emits oci_request_error, and permits a later explicit request. The native hanging-peer regression requires actual repeated overlap refusals, no success event, peer-side EOF, a retained session handle and successful fresh native tags read. Declared action log templates describe only fixed request intent; they contain no credential or payload substitutions and infer no native success.

Use common AppState instruction/memory and LLM/static/script/manual handlers, not protocol-specific state storage. Native errors carry actual bounded OCI code/message/detail; no partial body becomes a success. Primary references: [OCI Distribution1.1.1](https://github.com/opencontainers/distribution-spec/blob/v1.1.1/spec.md), [Distribution token authentication](https://distribution.github.io/distribution/spec/auth/token/), [pinned crane registry](https://github.com/google/go-containerregistry/blob/v0.22.1/pkg/registry/registry.go). Tests are explicitly registered in tests/client/oci_registry. No capture or conformance claim.

## Maturity: Beta

All four conditions of the client bar hold, on the real-server tests in `tests/client/oci_registry/`:

1. the peer is go-containerregistry's crane registry 0.22.1 — third-party, and not a library this client is built on;
2. a missing peer fails the test, never skips it;
3. a real session, completed against that server;
4. the client acts on the model's answer, asserted from the server's side: crane's request log shows the manifest fetch for the tag the mocked model picked out of the listing, and the verified digest is the pushed manifest's. Emptying the loop over the model's actions fails it.

Verified 1 November 2026 by running the suite against the installed peer and by that mutation. The CI job that installs the peer is in `.github/workflows/protocol-pairs.yml`.
